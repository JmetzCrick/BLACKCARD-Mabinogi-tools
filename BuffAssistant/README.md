# 블랙카드 도우미

Windows용 화면 캡처 기반 버프 알림 및 패스트핑 실행 도구입니다. .NET 8 Desktop Runtime이 필요합니다.

## 실행

`dotnet build BuffAssistant.sln -c Release`로 빌드한 뒤 출력 폴더의 `블랙카드 도우미.exe`를 실행합니다. 음악, 알림음, OCR 데이터와 배치파일을 포함한 출력 폴더 전체를 함께 사용하세요.

- 제작자 캐릭터 로딩 화면이 약 4초 표시됩니다.
- 현재 버전은 BETA 0.1이며 상단바에 표시합니다. 창 크기는 440×548입니다. 상단 접기 버튼은 기능 화면만 접고 상단 바를 남깁니다.
- 일정 사이트 버튼은 모든 탭의 공통 하단에 표시합니다. 버프 규칙 아래의 창 투명도는 상단바를 제외한 기능 화면에 적용하고 저장합니다.
- 버프 감지 탭에서 영역 선택 → 규칙 저장 → 감지 시작 순으로 사용합니다.
- 한국어 OCR 데이터는 `tessdata/kor.traineddata`에 포함됩니다. 원본·확대·주변 대비 보정 이미지를 함께 읽고, 인접한 한글 글자·단어를 묶어 버프명을 찾습니다. 반투명 창의 배경색 변화에는 주변 밝기 및 빨강 대비를 사용하며, 짧은 인식 끊김은 상태를 보존합니다.
- 버프명의 색이 아니라 같은 줄의 오른쪽 타이머를 읽습니다. 빨간 타이머의 `30초`가 두 번 연속 확인될 때 한 번 알립니다. 29초 이하나 단위 없는 숫자에는 알리지 않고, 갑자기 튀는 값은 걸러냅니다. 시간 연장은 세 프레임 확인 후 다음 30초 알림을 허용합니다.
- 감지 영역에는 버프명과 오른쪽 시간 숫자를 함께 포함하세요.
- 기본 알림음은 제공된 `음악버프30초.mp3`입니다. 각 버프의 음성 파일을 개별 변경할 수 있습니다.

## 음악

제공된 에탄 BGM은 `Assets/Music/Etain.mp3`로 포함되며 시작 시 자동 재생합니다.
창 상단에서 음악 선택, 반복, 재생/일시정지, 볼륨, 음소거를 조작합니다. 배경음악 볼륨과 버프 알림 볼륨(0~100%)은 별도 슬라이더로 조절하고 각각 저장합니다. 알림 볼륨은 재생 중에도 즉시 적용됩니다. 수동 정지 및 음소거 상태는 저장됩니다. 음성 알림 중에는 배경음악을 일시정지하며, 알림이 끝난 후에도 사용자가 정지한 음악은 재생하지 않습니다. 기존 버전 설정을 처음 불러올 때는 음악 정지 상태로 시작합니다. 이 버전은 중복 실행을 막습니다.
설정은 기존 호환성을 위해 `%LocalAppData%/BuffAssistant/settings.json`에 저장합니다.
기본 배경음악 볼륨은 10%입니다. 이전 버전의 높은 음량은 첫 실행 시 10%로 낮추고, 그 후 사용자가 조절한 음량은 저장합니다.

## 패스트핑

패스트핑 탭의 적용·해제 버튼은 사용자가 제공한 원본 배치파일을 관리자 권한으로 실행합니다.
실행 대기 위에는 설치 배치파일과 같은 전역 `TcpAckFrequency=1` 기준으로 적용 여부를 초록색/빨간색으로 표시합니다. 프로그램 시작, 탭 선택, 창 활성화 및 배치 실행 종료 시 다시 확인합니다.
적용은 TCP/IP 레지스트리 변경과 MSMQ 활성화, 해제는 해당 레지스트리 값 삭제와 MSMQ 비활성화를 수행합니다.
Windows 관리자 권한 요청을 승인하고 명령 창의 결과를 확인한 뒤 재부팅하세요.
해제 스크립트는 기존 값을 백업하여 복원하는 방식이 아닙니다.

## 경매장

한 글자부터 이름을 추천하며 선택하면 매물을 검색합니다. 매물을 선택하면 전체 페이지의 등록 수량, 개당 최저가, 최근 판매 가격과 날짜별 관측 거래 수량을 비동기로 조회합니다. 조회 중에도 창을 조작할 수 있고, 다른 품목을 선택하면 이전 조회를 취소합니다. 일부 페이지만 확인된 경우 물량을 일부 조회로 표기합니다.
넥슨 거래 내역 API는 최근 1시간만 제공합니다. 이전 날짜는 이 프로그램이 확인해 저장한 거래 기록이며 날짜 전체 거래량을 의미하지 않습니다. 거래 식별자로 중복 집계를 막고 기록은 최대 30일 보관합니다. API 데이터는 평균 약 10분 지연됩니다.
옵션이 없는 매물의 `item_option: null`도 정상 표시합니다.

## 업데이트 파일 공유

업데이트 탭에는 최신버전 확인 버튼 하나만 표시합니다. 공유 폴더의 `latest.json`을 읽어 비교하고, 새 버전이 있으면 빨간 안내와 확인 대화상자를 표시합니다. 확인을 누르면 ZIP을 준비하고 프로그램 종료 후 파일 교체와 재시작을 수행합니다. 실패한 교체는 이전 파일로 복원하며, 개인 API 키와 업데이트 서버 설정은 유지합니다.
상위 폴더의 `UpdateShare`에 현재 버전 정보와 배포 ZIP, 배포방법 안내를 제공합니다. 새 ZIP을 먼저 복사한 뒤 버전 정보를 변경하세요. 읽기 공유 권한과 호스팅 PC 연결이 필요합니다. 버전 정보에는 `version`, `downloadUrl`, `notes`, 선택적으로 ZIP의 `sha256`을 넣습니다.
공유 경로는 실행 파일 옆 `update-source.json`에 `{"feedPath":"\\\\컴퓨터이름\\공유폴더\\latest.json"}` 형식으로 설정할 수 있습니다. 설정 파일이 없으면 기존 저장 경로나 인접한 UpdateShare 폴더를 사용합니다.
음악 목록은 파일 내용으로 중복을 제거하므로 같은 BGM이 이전 빌드 폴더에 있어도 현재 번들 파일 하나로 표시합니다.

## 검증

상위 폴더에서 `dotnet run --project SmokeTests/SmokeTests.csproj -c Release`로 한국어 OCR 샘플, 버프 판정, 화면 로딩, 오디오 및 접기·펼치기를 검증합니다.
오디오 테스트는 음소거 상태로 진행하고, 패스트핑 테스트는 실행 경로와 관리자 실행 설정만 확인합니다. 배치파일을 실제 실행하지 않습니다.
실제 게임 OCR 정확도는 게임 화면에서 확인해야 합니다.

## OCR 데이터 출처

Tesseract 공식 [tessdata_fast 한국어 모델](https://github.com/tesseract-ocr/tessdata_fast/blob/main/kor.traineddata)을 사용합니다. 모델은 Apache-2.0 라이선스로 배포됩니다.
