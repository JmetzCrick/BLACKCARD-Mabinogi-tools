ZIP 전체를 압축 해제한 후 블랙카드 도우미.exe를 실행하세요.
Windows 10/11 64비트용이며 .NET 런타임이 포함되어 있습니다.
공통 경매장 API 키가 암호화되어 포함됩니다. 별도 키 입력은 필요 없습니다.

프로그램 시작 시 GitHub Releases의 최신 버전을 자동 확인합니다.
업데이트 탭의 최신버전 확인 버튼을 누르고 확인을 선택하면 ZIP을 내려받아
SHA256 검증 후 파일을 교체하고 다시 실행합니다. 실패 시 이전 파일로 복원합니다.
GitHub 로그인이나 개인 컴퓨터 공유 폴더 설정이 필요 없습니다.
기존 사용자 설정과 알림 음성 설정은 유지합니다.

음악버프 기능은 비활성화되어 있습니다.
음악버프 탭의 기존 메뉴는 흐리게 표시되며 실행할 수 없습니다.
배경음악 기본 음량은 10%이며 버프 알림 소리와 따로 조절할 수 있습니다.

구구 계산기는 등장 수의 2배 구슬과 1인당 분배, 1숲 올림을 계산합니다.
수수료 계산기는 기본 5% / 프리미엄 플러스 4%를 기준으로 계산합니다.
쿠폰 가격은 실제 구입 가격을 입력하세요. 0은 무료 보유 쿠폰입니다.

채집 시간 탭: 공식 모바일 홈페이지와 같은 에린 시계 계산식(현실 36분 = 에린 하루, 24초 보정)을 사용합니다.
채집 알람을 켜고 원하는 채집물을 체크하면 시작 시각에 한 번 알립니다. 다른 탭에서도 동작합니다.
알람 소리는 채집 탭에서 별도로 조절합니다. 프로그램 종료 중에는 알리지 않으며, PC 시간을 자동 동기화해 주세요.
창 투명도는 모든 탭의 공통 하단에서 조절합니다. 경매장 API 키는 프로그램 내부에 포함되어 별도 입력이나 키 파일이 필요 없습니다.

BETA 0.1.5: 상단 에린 AM/PM 시계는 기능창을 접어도 유지됩니다. 채집물별 시작/종료 시각은 에린 AM/PM으로, 타이머는 남은 현실 시간으로 표시합니다.
설정 탭에서 백그라운드 전환, Windows 로그인 시 자동 실행, 시작할 때 백그라운드 실행, 닫으면 트레이 전환, 항상 위 표시를 선택합니다. 트레이 아이콘을 두 번 클릭하면 열리며 우클릭 메뉴에서 종료합니다.
경매장 검색은 공백/숨은 문자를 정리하고 이름 조건 오류 시 키워드로 재조회합니다. 넥슨 API의 데이터 준비/점검/키 오류를 구분하여 표시합니다.
